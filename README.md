# TeachEasely — teacheasely.com

เว็บไซต์ของเพจ **Teacheasely | ง่ายเรื่องสอน เบาเรื่องงาน**
เขียนด้วย HTML / CSS / JavaScript ล้วน โฮสต์ฟรีบน GitHub Pages

## โครงสร้างไฟล์

```
teacheasely/
├── index.html          ← หน้าแรก (เนื้อหาทั้งหมดอยู่ที่นี่)
├── 404.html            ← หน้าที่แสดงเมื่อเปิดลิงก์ผิด
├── CNAME               ← บอก GitHub ว่าใช้โดเมน teacheasely.com (ห้ามลบ)
├── css/style.css       ← สี ฟอนต์ และหน้าตาทั้งหมด (สีหลักอยู่บนสุดของไฟล์)
├── js/main.js          ← เมนูมือถือ ค้นหา กรองเครื่องมือ ฟอร์มอีเมล
└── assets/images/      ← โลโก้ Teasy ไอคอน และรูปตอนแชร์ลิงก์
```

## แก้ไขบ่อยๆ ทำตรงไหน

| อยากแก้ | ไปที่ |
|---|---|
| ข้อความบนหน้าเว็บ | `index.html` (ค้นหาข้อความที่ต้องการแล้วแก้ได้เลย) |
| ลิงก์ปุ่ม Teasy Prompt Builder | `js/main.js` → `PROMPT_BUILDER_URL` |
| เพิ่มเครื่องมือใหม่ / เปลี่ยนเป็น "พร้อมใช้" | `index.html` ส่วน `TOOLBOX` (มีคำอธิบายในไฟล์) |
| สีของแบรนด์ | `css/style.css` → ส่วน `:root` |

## เชื่อมฟอร์มสมัครรับข่าวสารกับ Google Forms (ทำทีหลังได้)

1. สร้าง Google Form ที่มีคำถามเดียว: "อีเมล" (คำตอบสั้น)
2. กดจุด 3 จุด → **รับลิงก์ที่กรอกไว้ล่วงหน้า** → พิมพ์อีเมลอะไรก็ได้ → **รับลิงก์** แล้วคัดลอก
3. ในลิงก์จะมีคำว่า `entry.ตัวเลข` → นั่นคือ `emailField`
4. ลิงก์ฟอร์มที่เปลี่ยน `viewform` เป็น `formResponse` → นั่นคือ `formAction`
5. ใส่ 2 ค่านี้ใน `js/main.js` ส่วน `NEWSLETTER` แล้วอัปโหลดไฟล์ใหม่
   อีเมลที่คนสมัครจะไปอยู่ในชีตคำตอบของ Google Form

ถ้ายังไม่เชื่อม ฟอร์มจะบอกผู้ใช้ว่า "กำลังจะเปิดเร็วๆ นี้" และไม่เก็บอีเมลไว้ที่ไหน
